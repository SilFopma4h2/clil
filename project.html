clil - Terminal Coding Agent

clil is a tiny terminal coding agent designed for local LM Studio models. It provides powerful capabilities to inspect and manipulate files, run shell commands, and interact with AI models.

Key Features

  • ✓ Zero dependencies (no libcurl, no JSON library)
  • ✓ Small binary size (~200KB) with minimal RAM usage
  • ✓ Runs entirely on local models without internet connection
  • ✓ Works with any model that supports OpenAI-compatible chat completions

Architecture & Files

Core Components

  • main.cpp: Entry point and main REPL loop
  • agent.cpp: Agent loop handling turn execution and tool calls
  • lmstudio.cpp: LM Studio server communication and model management
  • http.cpp: Custom HTTP/1.1 client for communication with LM Studio server
  • json.cpp: Custom JSON parser and serializer (no external dependencies)

Utility Components

  • tools.cpp: Implementation of all available tools (read, write, edit, bash, search)
  • state.c: Shared state management for multiple clil instances

Available Tools

  • bash: Run shell commands non-interactively
  • read: Read a text file or list directory contents
  • write: Create or overwrite a file with content
  • edit: Replace one exact occurrence in a file
  • insert: Insert text after specified line number (0 = at start)
  • search: Search files recursively with regex pattern matching

Build & Usage

make                      # builds ./clil
make test                 # run unit tests (if available)

clil                        # interactive session
clil -m qwen/qwen3-coder-30b  # pick a model and context size
clil "fix this bug in main.cpp"

Slash Commands

  • /help: Show all available slash commands
  • /models: Show downloaded models with tool support info
  • /load <model name>: Load model into LM Studio
  • /unload [name]: Unload a loaded model
  • /server [start|stop|status]: Control LM Studio server
  • /ctx: Show current context usage
  • /clear: Start new conversation with fresh context
